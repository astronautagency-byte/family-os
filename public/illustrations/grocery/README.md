# FamOS flat grocery library v1

48 named illustrations in a transparent PNG atlas, generated with the built-in image-generation tool. Original generated artwork, not extracted from the supplied watermarked reference. This is a raster library, not editable vector source.

Use `GroceryIllustration` with `icon="apple"` for an explicit selection or `name` and `category` for automatic matching. `src/data/groceryIcons.js` is the named registry and crop manifest. Existing household/product photos retain priority. Generic category fallbacks are representative rather than exact product illustrations.
